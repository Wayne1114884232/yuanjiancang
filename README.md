# 元件仓 · 多人测试版 2.0.0-beta.1

云端部署候选版本；部署前先完成本地多人验收。旧单人版已到 v1.7，多人版统一使用 2.0.0-beta.1，电脑页面、服务和 APK 版本一致。按原来 1.6 / 1.7 / 1.8 的功能安排分组验收。

## 打开电脑端与安装手机 APK

1. 双击本目录的 `启动多人测试版.bat`，打开 `http://127.0.0.1:4187/`。电脑需 Node.js 22.13 或更高版本；本机已安装 22.19。
2. 首次选择“注册新账号”。账号为 3～40 位中英文、数字或 `_ . @ -`，密码为 8～128 位。每个人单独注册自己的账号，每个新账号有一个空的“我的库存”。当前没有预设账号或默认密码，也未提供邮件找回密码。
3. 在“设置与备份 → 显示连接地址”查看电脑当前地址。手机和电脑先连接同一可信局域网；2026-09-14 构建时电脑 WLAN 地址为 `http://10.10.40.233:4187/`，换网络后可能变化。
4. 手机浏览器打开该地址加 `downloads/component-hub.apk`，下载并安装“元件仓·多人测试”。APK 也保存在上一级目录 `元件仓多人测试版-v2.0-beta.1.apk`。这是可直接安装的 Android APK，可与原单人 APP 并存。
5. APK 首次启动会让你确认服务器地址。以后可在登录页或“设置与备份”修改。用同一账号登录电脑和手机可查看相同的库；朋友用自己的账号加入共享库。

服务启动后应保持运行。双击脚本启动时，关闭该服务窗口即停止服务。本次准备工作启动的后台测试服务可通过 Windows 任务管理器结束对应的 Node.js 进程；不要误结束旧单人服务。

## 第一组：账号、独立库、成员与迁移

- 用自己的账号进入“我的库存”，确认是空库。电脑浏览器打开 `http://127.0.0.1:4187/`，在“设置与备份 → 预览并迁移旧版库存”核对数量，再由你确认复制。仅所有者可迁移，目标须为空库，同一份旧库存不能反复迁移。原单人库存保留，两个版本之后独立记账。
- 点击右上角“库”或当前库名称，新建“学校实验室”“项目组”等独立库。切换时物料、BOM编辑、选中项、离线缓存和草稿均按账号与库分开。
- 在“成员与协作 → 邀请成员”生成邀请码。对方注册后进入“切换库 → 邀请码加入”，输入一次性邀请码。
- 在同一电脑用普通浏览器窗口和无痕窗口登录两个测试账号，即可先核对库隔离和协作，不必先准备第二台电脑。

| 角色 | 主要权限 |
| --- | --- |
| 所有者 | 管理库、成员、管理员、审批规则及旧数据迁移 |
| 管理员 | 物料资料、出入库、普通成员管理、备份恢复及审批 |
| 可出入库成员 | 在授权地点和项目中入库、领料、BOM记账；共享资料编辑与批量整理由管理员负责 |
| 只读成员 | 查看、搜索和按授权范围导出，不允许修改库存 |

BOM 入库可自动新建未有的元件；BOM 出库按板数和损耗扣账。螺丝、测试点等默认排除，也可强制纳入。元件库“全选 → 批量出库”仍需最后确认，确认后实际扣账。

## 第二组：协作、审批、备份和离线

- 两个账号同时打开同一库，一个人出库，另一个在线页面自动更新。若双方基于同一旧数量提交，只允许一笔成功，另一笔提示刷新后核对；同一次请求重试不重复扣账。
- 给普通成员限定一个地点和指定项目，检查其搜索、导出及记账范围。管理员可以查看审计记录；普通成员仅查看自己的记录。
- 项目预留显示负责人。预留保留实物数量，并限制其他出库占用已预留数量，实际项目领料才扣账。
- 至少有两位所有者/管理员时可开启敏感审批。损耗、盘点、撤销和恢复先待审批，另一位管理员批准后才改变库存；不能审批自己提交的申请。期间库存或权限变化会要求重新核对。
- “我的登录设备”可撤销会话。“设置与备份”可下载当前库 JSON、保留库内备份或预览恢复；恢复前自动备份，保留本库成员与权限。完整账号及成员数据库为 `data/team.sqlite`，要备份整个服务请停服后复制整个 `data` 目录。
- APK 成功同步后，停止电脑服务再重新打开 APK，应能看到最后一次快照、快照时间及离线标识。临时领用可存草稿，重新联网后人工核对再提交。退出账号会清除该账号本设备的快照和草稿。管理员撤销权限在设备重新联网时生效，已经离线保存的数据无法远程擦除。

## 第三组：协作增强

- 在两个你均可管理的库之间调拨：一次提交同时减少来源库并增加目标库，目标无该元件会建档；同型号参数冲突则整笔拒绝。跨库调拨不能单端撤销，需要反向调拨。开启敏感审批的库本测试版暂不支持跨库调拨。
- 库编号可用于申请加入，由管理员处理；邀请码可设 1～30 天、一次使用，并可提前撤销。
- 只读分享仅显示型号、参数及数量，不显示库位、成员、价格、流水。分享可到期或撤销；本地分享链接的接收人仍须能连接电脑所在网络。
- 管理员可以给采购项分配负责人，负责人或管理员确认部分到货，并记录最近确认人；其他普通成员不能替负责人确认。

## 当前边界与验证

数据保存在本机 SQLite，当前目录仅为云端部署候选，尚未创建 Render 服务或产生费用。当前同网联机可同步；电脑关闭后，手机查看已保存快照并记录草稿。不同网络的持续联机与电脑关机后的云端协作属于后续接云阶段。

采购跳转立创商城、芯片资料跳转制造商官方链接。多人本地测试阶段由管理员手动刷新立创阶梯报价并按阈值产生提醒；自动定时检查与自定义厂商消息源暂未接入此版。当前报价币种沿用立创接口提供的美元，不能当成人民币价格使用。

已通过 53 项自动检查，包括原单人服务回归、多角色与库隔离、HTTP并发与实时通知、审批和设备撤销、备份恢复、迁移、跨库原子性、BOM与全选最终扣账。另以页面事件模拟验证注册、邀请、切库、离线恢复和最终库存变化。APK 已构建并验签。

这些结果不等于手机实机验收。当前工具的浏览器自动验收受到管理员策略限制，未完成浏览器视觉操作或 Android 真机验收。请先按以上三组使用少量测试库存核对，再决定正式切换。
